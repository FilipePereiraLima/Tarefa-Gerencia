# Tarefa-Gerencia

Este é um repositório para a tarefa de Gerência e Configuração de Serviços para Internet.

## Estrutura

- `index.html` - Página principal
- `style.css` - Estilos da página
- `script.js` - Scripts de interatividade
- `erro.txt` - Registro de erros
- `imgs/` - Pasta com imagens das distribuições Linux

## Como usar

Abra o arquivo `index.html` em seu navegador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
